# IDEA PARKING - DEVVERSE

Ide yang muncul saat v1 sedang dibangun, dan sengaja tidak masuk v1. Format satu baris,
dengan alasan parkirnya. Tidak ada yang dihapus dari sini; kalau sebuah ide ditolak
permanen, tandai `REJECTED` beserta alasannya supaya tidak diajukan ulang tanpa sadar.

| Ide | Status | Target | Alasan diparkir |
| --- | --- | --- | --- |
| Build Lab: JSON formatter, regex tester, markdown editor | PROPOSED | v2 | Kategori sudah dimenangkan IT-Tools (80+ alat, gratis) dan DevToys. Masuk hanya kalau ada trafik yang memintanya. |
| SQL playground | PROPOSED | v2 | Butuh eksekusi query yang aman di server - permukaan keamanan baru, bukan fitur kecil. |
| API Lab: HTTP request builder + response viewer | PROPOSED | v2 | Kategori dimenangkan Postman, Hoppscotch, Bruno. Nilainya hanya sebagai alat di dalam alur, bukan menu sendiri. |
| AI Dev Assistant (explain code, explain error) | PROPOSED | v3 | Biaya per pengguna dan paling mudah ditiru. Butuh model biaya yang jelas dulu. |
| Learning Quest: mini challenge + roadmap | PROPOSED | v3 | Butuh kurikulum, dan kurikulum butuh manusia yang menyusunnya. |
| Developer Vault: snippet + prompt library | PROPOSED | v3 | Komoditas. Gist, Notion, dan Raycast sudah ada di sana. |
| Skill tree visual + achievement badge | PROPOSED | v2 | Baru berarti kalau sudah ada data bukti dari banyak proyek. Membangunnya lebih dulu = gamifikasi tanpa sesuatu untuk digamifikasi. |
| Daily Dev Challenge | PROPOSED | v3 | Butuh bank soal dan penilaian otomatis; dua produk tersendiri. |

| Tech Discovery (katalog tools dan library) | PROPOSED | v3 | Butuh kurasi manual yang cepat basi. |
| Repository privat | PROPOSED | v2 | Butuh scope OAuth tambahan dan kewajiban menyimpan kode orang lain. |

| Bahasa Inggris sebagai bahasa kedua UI | PROPOSED | v2 | Menambah permukaan terjemahan sebelum ada satu pengguna pun. |
